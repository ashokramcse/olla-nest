# Contributing to Olla Nest

Thanks for considering a contribution.

Olla Nest is an early local-first AI workspace for companies using Ollama. The project should stay simple, understandable, and easy to run on a local machine.

## Contribution Principles

- Keep the product local-first by default.
- Make admin controls clear and practical.
- Keep employee workflows simple.
- Show model routing decisions transparently.
- Avoid adding heavy infrastructure unless it clearly improves the MVP.
- Prefer readable code over clever abstractions.

## Useful Areas to Help

- Model catalog management
- Admin policy editing
- Authentication
- Workspace and file access
- Better router scoring
- UI polish
- Tests
- Documentation

## Local Setup

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Before Opening a Pull Request

- Run the app locally.
- Test at least one admin flow and one employee flow.
- Keep commits focused and clearly described.
- Update documentation when behavior changes.
